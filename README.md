# Rainfall Prediction Using Machine Learning
  In this project technologies like Randforest,streamlit,sklearn used. Datataset used in this project taken from 
  kaggle (https://www.kaggle.com/code/fireeagle123/rainfall-prediction-using-machine-learning).

  In this project data preprocessing, EDA and model traning done in kaggle notebook (https://www.kaggle.com/code/fireeagle123/rainfall-prediction-using-machine-learning)
  I stored the trained model and its features in model.pkl file using python pickle library and used here in this application 
   to predict the weather.
